# Reference: SOP Retrieval — Reusability Notes

This retrieval pattern — metadata-filtered vector search restricted to current-approved-version documents, returning a section rather than a document — is directly reusable by **Quality** for retrieving the specific inspection/test procedure relevant to a detected process deviation, and by **EHS** for retrieving the exact safety procedure/permit-to-work section relevant to a hazard condition. It is also reusable for **Training** material lookup across any department. Only the SharePoint library and metadata schema need to be swapped.

# Reference: Maintenance Report Writer — Reusability Notes

This drafting-with-human-gate pattern is directly reusable by **Quality** for drafting non-conformance reports and CAPA closure documentation, and by **EHS** for drafting incident reports pending safety officer review. The core mechanism — synthesize structured diagnostic/planning data plus human field input into standardized documentation, with mandatory human approval before any system-of-record write — transfers to any department with a similar "diagnose -> act -> document" workflow and a system of record equivalent to SAP PM.

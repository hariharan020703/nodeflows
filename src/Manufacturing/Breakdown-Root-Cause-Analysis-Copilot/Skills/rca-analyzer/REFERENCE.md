# Reusability Notes — RCA Analyzer

The pattern — structured, citation-enforced LLM reasoning over a deterministic evidence package, with an explicit confidence cap under partial data — is reusable by Quality (root-causing a defect against process-parameter timelines and historical defect investigations) and by Production (diagnosing recurring schedule-adherence misses). Only the evidence package composition changes; the reasoning-and-citation-enforcement pattern does not.

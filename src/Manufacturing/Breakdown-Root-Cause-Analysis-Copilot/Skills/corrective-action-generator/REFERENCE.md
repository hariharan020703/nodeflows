# Reusability Notes — Corrective Action Generator

The "root cause → immediate + preventive action, checking whether a similar past fix already failed" pattern is directly reusable by any department running a Corrective and Preventive Action (CAPA) process — Quality's CAPA workflow for defect root causes, or EHS's corrective action tracking for safety near-misses — with the same discipline of not repeating a documented-ineffective fix.

# Reusability Notes — Checklist Generator

This retrieval-plus-overlay-plus-reliability-feedback pattern for generating task instructions is reusable by:

- **Quality** — generating inspection/audit checklists from quality-manual sections.
- **EHS** — generating statutory-inspection checklists from regulatory manuals with permit flags already built in.

The retrieval corpus (OEM manuals vs. quality manuals vs. regulatory codes) is the only element that changes.

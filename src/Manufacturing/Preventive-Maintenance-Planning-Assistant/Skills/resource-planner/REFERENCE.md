# Reusability Notes — Resource Planner

The certification-matching plus free/busy plus workload-balancing pattern is directly reusable by:

- **Quality** — assigning certified auditors/inspectors to scheduled audits.
- **EHS** — assigning certified safety inspectors to statutory equipment checks.
- **Production** — assigning changeover-certified operators to changeover windows.

Only the certification taxonomy and calendar source need to be reconfigured.

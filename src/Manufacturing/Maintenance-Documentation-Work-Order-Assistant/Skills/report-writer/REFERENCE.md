# Report Writer — Reusability Reference

The document-drafting pattern — fuse chronological field notes into a cited narrative, explicitly flag unsupported claims, gate on human sign-off — is directly reusable by Quality (drafting a corrective-action closure document from inspector notes) and by any department producing after-action or incident documentation, including EHS incident write-ups and Production shift-loss narratives. Only the target document template and grounding document library (SOPs vs. quality procedures vs. EHS policies) need to change.

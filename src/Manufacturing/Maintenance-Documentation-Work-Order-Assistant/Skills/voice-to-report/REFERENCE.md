# Voice-to-Report — Reusability Reference

This skill is directly reusable by any manufacturing department where frontline staff narrate observations verbally rather than typing them: Quality (inspector voice notes on non-conformances), EHS (incident/near-miss voice reports), and Production (shift operator voice logs on line stoppages). The maintenance-vocabulary correction layer is the only component requiring department-specific tuning — swapping in a Quality or EHS terminology list makes the same ASR-plus-correction pipeline reusable with no structural change.
